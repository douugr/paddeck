## App Review notes (App Review Information › Notes)

PadDeck is a remote trackpad/keyboard for the Mac. It needs the free companion app "PadDeck for Mac", which receives the input and turns it into keyboard and pointer events (the same model as other remote-mouse apps).

How to test:
1. On a Mac (macOS 12+), download PadDeck-mac.zip from https://github.com/douugr/paddeck/releases/latest, unzip it, move PadDeck to Applications and open it. It is signed with Developer ID and notarized. A keyboard icon appears in the menu bar.
2. When asked, allow PadDeck in System Settings › Privacy & Security › Accessibility (needed to move the pointer and type).
3. Put the iPhone/iPad on the same Wi-Fi network, open PadDeck and allow Local Network access.
4. Tap the Mac in the list and enter the 4-digit PIN shown in the PadDeck menu on the Mac's menu bar.
   Alternative: connect the iPhone/iPad to the Mac with a USB cable while PadDeck is open; it connects without a PIN.
5. Move a finger on the trackpad, type on the keyboard, and try the Shortcuts tab.

There are no accounts, logins or in-app purchases. The app does not collect any data.
