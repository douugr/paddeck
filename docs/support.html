Common questions

My Mac doesn't show up in the list. Make sure PadDeck is open on the Mac (keyboard icon in the menu bar), both devices are on the same Wi-Fi network, and Local Network access is allowed in iOS Settings › PadDeck. You can also connect by IP, or use a USB cable.

It connects but the pointer doesn't move. Allow PadDeck in System Settings › Privacy & Security › Accessibility on the Mac. If it's already there, remove it and add it again.

The PIN is refused. The PIN is shown in the PadDeck menu on the Mac and changes if you choose "New PIN". After 5 wrong attempts, wait a minute.

The firewall asks about incoming connections. Allow them for PadDeck: that's how the iPhone or iPad reaches the Mac.

How do I use the cable? Open PadDeck on the iPhone or iPad and plug it into the Mac. If iOS asks whether to trust the computer, tap Trust.

Accents and emoji. Hold a letter for accents, or tap the áç key to use the iOS keyboard (emoji and dictation).
